# Rolling_the_Dices
A simple Python mini project that simulates rolling a dices by clicking Roll dice button.
Roll the Dices – Python Mini Project
Its a simple Python mini project that simulates rolling the dices by clicking Roll Dice button .
Mainly we used random module to generate the number between (1 to 6) .

#Features

-Simple dice roll simulation
-Flask web interface to display results
-HTML template for output design
-Random number generation
-Allows user to roll multiple times
-User can click 'exit' to stop the game

#Technologies Used

-Python 3.8
-Flask (Python Web Framework)
-HTML (Frontend Template)
